# chrome-double-click-close-extension-
A lightweight Chrome extension that allows you to close tabs by double-clicking on empty areas. Features smart mis-click prevention (skips buttons, links, inputs, and text selections) and includes a quick toggle switch.
Key Features :
Double-Click to Close: Instantly close tabs with a double-click on any empty area of a webpage.
Smart Avoidance: Automatically ignores clicks on interactive elements like buttons, links, and input fields.
Selection Protection: Prevents closing the tab when you are double-clicking to select or highlight text.
Toggle Switch: Easily enable or disable the extension via the popup menu.
Capturing Phase Logic: High reliability even on complex websites with custom event handling.
